# crypto-service-sdk-python 0.0.40

## Highlights ⭐️

- First release of the Python SDK for the Crypto Service REST API, in
  lockstep with crypto-service 0.0.40.
- `AsyncClient` and the blocking `Client`, with one typed method for each
  of the 59 v2 operations, plus the probes, the algorithm catalogue and
  the DORA and CBOM documents.
- Opt-in retries with the suite's retry-safety table, per-attempt
  timeouts and an overall deadline, RFC 9457 problems as `ApiError`.
- Tested against crypto-server with the suite's conformance kit on every
  pull request.
