# crypto-service-sdk-python 0.0.41

## Highlights ⭐️

- Typed methods check each success response against the types in
  `crypto_service.types` before returning it; a response that does not
  match raises `TransportError` naming the member, never its value.
- Credentials, the traceparent and the raw `request()` method, path and
  headers are checked against allowlists (visible ASCII, token68, W3C
  Trace Context, RFC 9110 tokens). `request()` refuses a path with a
  scheme or a host, which would have sent the credentials to another
  origin.
- An assurance case (`docs/ASSURANCE.md`), a recorded security review
  and the steps to reproduce a release and verify its attestations.
